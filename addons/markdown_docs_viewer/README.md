# Markdown Docs Viewer

Adds a **Docs** tab next to 2D, 3D and Script that renders your project's Markdown files.

1. Enable **Markdown Docs Viewer** in **Project > Project Settings > Plugins**.
2. Click the **Docs** tab at the top of the editor.

`Ctrl + Mouse Wheel` zooms. Click a heading in the outline to jump to it.

Images and raw HTML are not rendered. Files inside `addons/` are not listed.
